RODA DAS COMPETÊNCIAS — SÉCULO XXI | V37

Abra index.html no navegador com os arquivos da pasta juntos.

1. Escolha COLETIVA, depois clique em MINHAS TURMAS para cadastrar e selecionar uma turma.
2. Em MINHAS TURMAS, clique INICIAR EXPERIÊNCIA COLETIVA.
3. Registre respostas e intervenções. Use SALVAR EXPERIÊNCIA ATUAL para arquivar uma versão no histórico.
4. Use EXPORTAR DADOS (JSON) para fazer backup e IMPORTAR DADOS (JSON) para restaurar/mesclar.
5. Cada experiência arquivada pode ser reaberta em RESULTADOS ou INTERVENÇÕES.

Importação: arquivos de backup V37 e exportações V36 são aceitos; importação é validada e confirmada antes de salvar.
Armazenamento: localStorage do navegador. Não há sincronização entre dispositivos, login ou servidor remoto.
Proteção de dados: não registre nomes de estudantes ou informações sensíveis. Proteja os backups JSON.

IMPORTANTE: uma experiência reaberta pode ser editada; salve uma nova versão no histórico ao concluir.

V38: Seletor de turma exibe apenas dados da turma escolhida. Cada turma tem um único registro atualizado a cada salvamento, com data/hora da última edição. Registros múltiplos antigos são consolidados pelo mais recente. A importação JSON preserva apenas o registro mais recente por turma. Faça backup antes de substituir dados.
